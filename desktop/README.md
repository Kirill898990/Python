# «Простая химия» для Windows 10/11

Окно с сайтом урокискириллом.рф: своё приложение со значком на рабочем столе и в меню «Пуск».
Всё содержимое — это сам сайт, поэтому приложение обновляется вместе с сайтом, переустанавливать не нужно.

Что добавляет приложение к сайту:

- отдельное окно, которое запоминает размер и положение;
- микрофон и камера для звонков в курсе (только для нашего сайта);
- меню и контекстное меню на русском, исправление опечаток;
- экран «Нет связи» с кнопкой «Повторить» (и сам повторяет, когда появится интернет);
- чужие сайты (например, оплата ЮKassa) открываются в обычном браузере.

## Сборка

Установщик собирает GitHub (Actions → «Приложение для Windows»), когда меняется эта папка.
Из ветки main готовый файл выкладывается в Releases, ссылка для скачивания постоянная:
`https://github.com/Kirill898990/Python/releases/latest/download/ProstayaHimiya-Setup.exe`.

Новая версия приложения: поднимите `version` в `package.json`.

На своём компьютере с Windows: `npm ci`, потом `npm start` (запустить) или `npm run dist` (собрать установщик в `dist`).
Проверка правил без Electron: `node test.js`.

Установщик не подписан сертификатом (он стоит денег), поэтому при первом запуске Windows может показать
«Windows защитил ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
