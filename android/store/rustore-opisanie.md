# Тексты для страницы приложения в RuStore

Это черновик, поменяйте его как хотите.

## Название
Простая химия

## Краткое описание
Практики по химии и биологии для 5–10 классов с мгновенной проверкой

## Полное описание
«Простая химия с Ириной» — тренажёр по химии и биологии для школьников 5–10 классов.

Что внутри:
• Задания на составление формул по валентности с мгновенной проверкой
• Расстановка коэффициентов в уравнениях реакций: приложение само посчитает атомы и покажет, где ошибка
• Подсказки и правильные ответы к каждому заданию
• Вопросы по теории: ответь своими словами и отправь учителю прямо из приложения
• Ссылки на теорию ЯКласса по классам
• Прогресс сохраняется, черновики ответов не теряются
• Светлая и тёмная тема

Задания и проверка работают без интернета. Интернет нужен только для отправки ответов учителю и для открытия теории.
